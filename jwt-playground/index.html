1. Mengapa JWT Disebut Stateless?

Server tidak perlu menyimpan token di database atau memory RAM. Cukup verifikasi tanda tangan digitalnya. Ini membuat GoFood backend sangat cepat dan mudah di-scale horizontal.

2. Mengapa Payload Bukan Rahasia?

Payload hanya di-encode dengan Base64Url, bukan dienkripsi. Siapapun bisa membaca isinya. Karena itu, JANGAN PERNAH menyimpan password di dalam payload JWT!

3. Apa Fungsi Signature?

Signature menjamin integritas. Jika seorang hacker mengubah isi payload (misal: mengubah CUSTOMER menjadi ADMIN), signature tidak akan cocok dan request langsung ditolak dengan 401 Unauthorized.
